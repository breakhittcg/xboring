# XBoring — Chrome Extension

Automatically hides boring posts from your X (Twitter) feed.

## Default filters

- "what are you building today?"
- "i want to connect with"
- "let's connect", "looking to connect"
- "drop your", "tag someone who"
- "humbled to", "thrilled to share"
- "gm gm", "follow for follow"
- ... and many more

## Installation (Chrome / Edge / Brave)

1. Open Chrome and go to `chrome://extensions/`
2. Enable **Developer mode** (toggle in the top right)
3. Click **"Load unpacked"**
4. Select the `xboring` folder
5. The extension appears in your toolbar 🎉

## Usage

- Click the icon in your toolbar
- Enable/disable filtering with the ON/OFF toggle
- Add your own keywords to filter
- Remove filters you don't need
- The counter shows how many posts have been hidden

## Add custom filters

Type a keyword or phrase in the input field and click **+ Add**.  
Examples: `"just launched"`, `"10x engineer"`, `"my thread on"`
